# HarborRAG documentation website

Source for **https://cbtw-apac.github.io/harborrag-doc-website/** - the public documentation site for [HarborRAG](https://github.com/cbtw-apac/HarborRAG).

> **Content is not authored here.** Every page under `website/docs/` and `website/versioned_docs/` is synced automatically from [`cbtw-apac/HarborRAG/docs`](https://github.com/cbtw-apac/HarborRAG/tree/main/docs). To fix or add documentation, open a pull request there. Pull requests that edit synced content in this repository will be closed.

## How it works

```
cbtw-apac/HarborRAG  ──release / docs push ──►  repository_dispatch  ──►  sync.yml
                                                                          │ ingest (Python)
                                                                          ▼
                                                              auto-merged PR → deploy.yml → GitHub Pages
```

| Site version    | Comes from                                                    |
| --------------- | ------------------------------------------------------------- |
| `Next`          | HarborRAG `main` (or the latest pre-release tag)              |
| `2.0`, `2.1`, … | newest stable release on that minor line; hotfixes refresh it |

A nightly cron and a manual `workflow_dispatch` on **Sync docs from HarborRAG** act as fallbacks if an event is missed.

Design and runbook: Confluence → _HarborRAG documentation website — two-repo sync architecture_ and _— scaffold and build guide_.

## Repository layout

| Path                                                                      | What                                                                                    | Edit by hand?                     |
| ------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- | --------------------------------- |
| `website/`                                                                | Docusaurus 3 site (TypeScript, pnpm)                                                    | yes - theme, landing page, config |
| `website/docs/`, `website/versioned_docs/`, `website/versioned_sidebars/` | synced content                                                                          | **no**                            |
| `website/sidebars.ts`, `website/versions.json`, `website/sync-state.json` | generated by the ingest script                                                          | **no**                            |
| `scripts/ingest/`                                                         | Python (`uv`) ingest: copy, frontmatter, link rewrite, TOC → sidebar, publication guard | yes                               |
| `.github/workflows/`                                                      | `sync.yml`, `pr-check.yml`, `deploy.yml`                                                | yes                               |

## Local development

Prerequisites: Node 20+, pnpm (version pinned in `website/package.json`), Python 3.12 + `uv`, a local checkout of HarborRAG.

```bash
# site only (placeholder or last synced content)
cd website && pnpm install && pnpm start

# preview a HarborRAG docs change before it is merged
make sync-local HARBORRAG=../HarborRAG   # ingest main into website/docs
make dev

# what CI runs
make check                               # ingest tests + typecheck + strict build
```

Do not run `corepack enable`; pnpm is already the pinned manager.
