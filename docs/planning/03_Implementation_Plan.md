### 2.2 Models and CLI

`models.py` — frozen dataclasses mirroring the TypeScript types in `docusaurus.config.ts` (keep field names identical, they are serialised to `sync-state.json`):

```python
Channel = Literal["main", "prerelease", "stable"]

@dataclass(frozen=True)
class SyncEntry:
    label: str
    channel: Channel
    source_ref: str | None
    source_sha: str | None
    synced_at: str | None          # ISO-8601 UTC

@dataclass(frozen=True)
class SyncState:
    current: SyncEntry
    versions: dict[str, SyncEntry]  # "2.0" -> entry

@dataclass(frozen=True)
class IngestRequest:
    source: Path; site: Path; channel: Channel
    product_version: str            # "2.0.1" | "2.1.0a1" | "auto" (read root pyproject)
    source_ref: str; source_sha: str
    keep_minors: int = 2; dry_run: bool = False; force: bool = False

@dataclass
class Doc:
    source_path: Path       # relative to HarborRAG root, e.g. docs/users/chat/README.md
    target_path: Path       # relative to docs target dir, e.g. users/chat/README.md
    title: str
    body: str
    frontmatter: dict[str, object]
```

`ingest.py` — argparse with the flags from `02_…` §3; `--product-version auto` reads `[project].version` from the source root `pyproject.toml` (`tomllib`). Derive `minor_line = "X.Y"` and `is_prerelease` with `packaging.version.Version`.

Tests: `test_models.py` — `SyncState` round-trips through JSON with the exact keys the TS side expects.

### 2.7 Link rewriting

`links.py` — port `markdown_links.py` rules, driven by a `mapping: dict[Path, str]` of *source path → site route* built from 2.3 + 2.8:

| Source link (in `docs/users/chat/README.md`) | Result |
|---|---|
| `../configuration/README.md` | `/docs/users/configuration/README` (or relative `../configuration/README` — pick relative, Docusaurus resolves versions correctly with relative file links) |
| `../../CONTRIBUTING.md` | `/docs/project/contributing` |
| `../../packages/harborrag/README.md` | `/docs/packages/harborrag` |
| `x.md#anchor` | rewritten path + `#anchor` |
| `https://github.com/cbtw-apac/HarborRAG/...` | unchanged |
| relative link with no mapping entry | **error** listing file + link (this is how broken source links surface) |

Prefer keeping links **relative and `.md`-suffixed** where possible: Docusaurus rewrites `./foo.md` file links itself and keeps them correct inside `versioned_docs/`. Only root/package bridges need absolute routes.

Tests: one test per row above, using real link strings harvested from HarborRAG (`grep -rhoE '\]\((\.\./)+[^)#]+' docs`).

**Commit:** `ingest: link rewriting`

### 2.9 Writer, state, idempotency

`writer.py` — build the whole output tree in a temp dir, then swap into the target (`website/docs/` for `main`/`prerelease`); write `sidebars.ts`; update `sync-state.json` (`current` for main/prerelease); leave `versions.json` untouched for these channels. Then compare the result with the committed tree: if byte-identical for the same `source_sha`, exit 0 and print `no changes`; the workflow uses this to skip the PR. `--dry-run` prints the file plan only. `--force` rewrites even when `sync-state` already has this `source_sha`.

Tests: running twice on the fixture yields no diff the second time; a failing guard leaves the target untouched (temp-dir swap).

**Commit:** `ingest: atomic writer, sync-state, idempotency`
